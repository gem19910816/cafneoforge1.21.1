# 僵尸生存套件 — 1.20.1 Forge → 1.21.1 NeoForge 移植说明

## 1. 来源与方法

- 源码：官方仓库 [Scarasol/Zombie-Survival-Kit](https://github.com/Scarasol/Zombie-Survival-Kit) `1.20.1` 分支（GPL v3）
- 方法：基于官方源码逐包适配，**非反编译**。注册 ID、模型、贴图、geo 动画全部保持不变。
- 目标：NeoForge 21.1.252 / MC 1.21.1 / Java 21
- 前置：Sona生存101（同仓库移植版）、GeckoLib 4.9.3

## 2. 构建方式

与 `Sona生存101/` 相同：不使用 ModDevGradle（NeoForge maven 不可达），以本地运行库为编译 classpath，
classpath 顺序 neoforge-client → neoforge-universal → mojmap-at → libraries → libs。
打包：`JAVA_HOME=<jdk21> gradle jar`。

## 3. 主要 API 适配

- `net.minecraftforge.*` → `net.neoforged.*`；网络包 8 个全部重写为 1.21 `CustomPacketPayload` 模式
- 武器/护甲属性系统：1.21 `ItemAttributeModifiers` + ResourceLocation id；`ModArmorMaterial` 由 enum 改为 `Holder<ArmorMaterial>` 静态常量（1.21 ArmorMaterial 是 record）
- GeckoLib 3 → 4：模型/渲染器/动画包名与签名适配（`CoreGeoBone`→`GeoBone`、rgba float→ARGB int 等）
- 方块交互：`use` 拆分为 `useItemOn`/`useWithoutItem`；方块 codec（`simpleCodec`）；`BlockPathTypes`→`PathType`
- 方块实体：`saveAdditional/loadAdditional(..., HolderLookup.Provider)`；Forge 能力 → `RegisterCapabilitiesEvent` + `Capabilities.ItemHandler`
- 菜单：`IForgeMenuType`→`IMenuTypeExtension`；`NetworkHooks.openScreen`→`IPlayerExtension.openMenu`
- 实体：删全部 `PlayMessages.SpawnEntity` 构造器与 `setCustomClientFactory`（NeoForge 自动生成刷怪包）
- 战利品表：嵌套子表引用 `"name"`→`"value"`（1.21 改名）；`set_nbt`→`set_components`；forge: 公共标签→c:
- 模型 JSON：`forge:separate_transforms`→`neoforge:separate_transforms`
- 数据包目录单数化（`loot_table`/`recipe`/`tags/item` 等）
- `EntitySpawnReason` 不存在于 1.21.1（1.21.2+ 才有），`MobSpawnType` 保持不变
- 热成像后处理：1.21 `RenderTarget` stencil API 移除；渲染线程 partialTick 改 `DeltaTracker`

## 4. 顺带修复的原版缺陷（经代码审查发现）

- **迫击炮强加载票等级不对称（add 3 / remove 15）**：每次炮击后区块永久强加载 → 对称化
- **炮弹区块卸载时 FORCED 票泄漏** → 全移除路径释放 + 坐标持久化兜底
- **热成像后处理每帧强制开启**（开关形同虚设）→ 仅在穿戴外骨骼且雷达模式时激活
- **防爆甲穿 2 件后减速永久残留**（updateModifier 缺 count==2 分支）→ 补齐
- `ShortwaveRadioBlock` 静态 Map 以 Level 为键（维度泄漏）+ 迭代中删除（CME 风险）→ ResourceKey + 迭代器删除
- **SyncBlockPacket 服务端零校验**（可改写任意坐标电台）→ 距离 + GUI 状态校验
- 三个 Menu 的 `quickMoveStack` 槽位区间损坏（shift-click 失效）→ 重写
- `LaunchSchedule.equals/hashCode` 只比区块 → 同区块第二次炮击被静默丢弃 → 加入坐标
- `Miracle` 负 amplifier 吸收心 → 修正；`Knife` 客户端幽灵伤害 → 服务端守卫
- `HeavyMachineGun`/`Mortar` 每 tick 实体扫描+全排序 → 节流 + 最近实体查找
- `FlareGunEntity` 用命令刷粒子（权限 4）→ 直接 sendParticles；`MortarShellEntity.smoke()` 20 次循环各发全服包 → 单次广播
- 近战武器每次查询重建属性 multimap → 缓存
- `new Random()` 散布 → ThreadLocalRandom；`Mixin` 局部表捕获 → MixinExtras WrapOperation（1.21 局部表不兼容崩溃的系统性修复）

## 5. 验证状态

- `javac 21` 编译 **0 error**（182 个源文件）
- 全部 mixin 注入点与 1.21.1 字节码逐一核对
- 实机（整合包 212 模组环境）：启动到主菜单、创建世界、区块保存人工实测通过
- 遗留小项：`grant_book_on_first_join` 的 patchouli 指南书组件依赖 patchouli 1.21 格式；KonnGara 唱片 1.21 数据驱动（JukeboxSong）未补 jukebox_song 数据文件，唱片暂无音乐。
