# SelfAid 急救护理

一个完全**自制**的分部位生命值 + 急救物品玩法模组（NeoForge 1.21.1）。玩法概念参考知名模组 First Aid，**代码为原创实现**。

## 玩法说明

### 分部位生命值
- 玩家身体分为 6 个部位：**头部(20%)、躯干(30%)、左臂(10%)、右臂(10%)、左腿(15%)、右腿(15%)**，比例乘以玩家最大生命值。
- 受到的伤害会分配到对应部位：
  - 弹射物（箭、三叉戟等）按命中高度判定：高处爆头、中部躯干、低处四肢；
  - 摔落/钟乳石伤害优先落在双腿和躯干；
  - 其余伤害按部位比例随机分配。
- **死亡规则**：头部清空、躯干清空、或 6 个部位全部清空时死亡（可在配置中调整）。
- **截肢惩罚**：手臂清空获得虚弱，腿部清空获得缓慢（双腿清空为缓慢 III）。
- 原版自然回血会自动分配到比例最低的部位；部位血量之和始终与玩家原生血量保持一致。

### 急救物品（物品栏创造标签「急救护理」）
| 物品 | 效果 | 配方 |
|---|---|---|
| 绷带 | 包扎一条随机肢体，6 秒共回 1.5 颗心 | 纸×2 + 线 → 绷带×2 |
| 创可贴 | 贴头部/躯干较伤一处，3 秒共回 1 颗心 | 纸 + 粘液球 → 创可贴×3 |
| 吗啡 | 清除负面效果，10 秒内全身共回 3 颗心 | 玻璃瓶 + 虞美人 + 糖 |
| 急救包 | 清除负面效果，15 秒内全身共回 6 颗心 | 皮革+绷带+铁锭+线+纸 的 3×3 配方 |

按住右键使用，使用完成后开始持续回血。

### HUD
屏幕左上角显示六格身体血量示意（绿=满，红=空），可在配置中关闭、缩放或移动。

## 安装

把 `selfaid-1.0.0.jar` 放进 `.minecraft/mods/`（或服务端 `mods/`），需要 NeoForge 21.1.255 及以上。单机/服务端均可，纯服务端也可运行（HUD 仅客户端绘制）。

## 命令

无命令。

## 配置

- `config/selfaid-common.toml`（服务端）：
  - `enableSystem` 是否启用分部位血量（默认 true）
  - `headDeath` / `torsoDeath` 头部/躯干清空是否死亡（默认 true）
  - `naturalRegenDistributes` 自然回血是否分配到部位（默认 true）
  - `limbPenalties` 空部位是否给予虚弱/缓慢（默认 true）
  - `damageScale` 部位承伤倍率（默认 1.0）
- `config/selfaid-client.toml`（客户端）：`showHud`、`scale`、`x`、`y` 控制 HUD。

## 构建说明

```
gradlew build
```
需要 JDK 21。成品在 `build/libs/selfaid-1.0.0.jar`。
