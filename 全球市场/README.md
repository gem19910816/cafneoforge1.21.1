# Global Market · 全球市场

> 「齿轮与腐肉」整合包的**官网中央市场**模组：挂单、余额、邮箱全部集中存放在官网服务端，
> 单机存档之间、不同服务器之间的玩家共享**同一个市场**。
> 从 1.20.1 Forge 版移植到 1.21.1 NeoForge，并把原本存在本地存档里的市场数据改为走官网 API。

- 平台：**NeoForge 1.21.1**（`neoforge >= 21.1`）
- 前置：无（货币 `caf:money` 由本模组自己注册）
- 许可：沿用原 1.20.1 全球市场模组，仓库内未附许可文件
- 产物：`gearsandflesh_market-1.0.0.jar`（约 128 KB）
- modId：`gearsandflesh_market`　包名：`com.gearsandflesh.market`

**客户端与服务端都必须安装本模组**（界面走 NeoForge 数据包，两端协议版本见 `MarketNetwork`）。

---

## 1. 它解决什么问题

1.20.1 版的市场把挂单存在**当前存档**里，所以：

- 单机玩家自成一个市场，卖不出东西也买不到东西；
- 每个服务器的市场互相隔离，人少的服等于没有市场；
- 创造模式刷出来的物品可以随地挂单，经济容易崩。

本版本把「市场数据」整体搬到官网：**能上网的玩家就共享同一个市场**，谁在哪个存档、哪个服务器都不影响。

| 项目 | 1.20.1 版 | 本版本 |
|---|---|---|
| 挂单存放 | 存档内的 `MarketSavedData` | 官网数据库 |
| 交易货币 | 实体物品 `caf:money` | **官网账号余额**（实体币可存取） |
| 邮箱/待领取 | 存档内队列 | 官网队列（跨存档、跨服） |
| 规则（白名单、限价、审批） | 无 | 官网服务端强制执行 |
| 谁的市场 | 单个存档 | 所有联网玩家 |

## 2. 玩法与命令

### 绑定（一次性）

1. 在官网注册账号，获取**绑定码**（由管理员在后台生成发放）；
2. 游戏内输入：

```
/market bind <绑定码>
```

绑定后这个存档就认这个官网账号（token 存在存档的 `gearsandflesh_market_world` 世界数据里）。

| 命令 | 说明 | 权限 |
|---|---|---|
| `/market bind <绑定码>` | 绑定官网账号 | 所有玩家 |
| `/market unbind` | 解除当前存档的绑定 | 所有玩家 |
| `/market` | 打开市场界面 | 默认仅管理员（见下） |
| `/market edit` | 管理员模式：右键挂单可复制/下架/销毁 | 权限等级 2 |

### 交易入口：市场终端方块

`gearsandflesh_market:market_terminal`

- **没有物品形态**：创造模式物品栏里搜不到，`/give` 也拿不到；
- 只能由管理员放置：

```
/setblock ~ ~ ~ gearsandflesh_market:market_terminal
```

- 玩家右键终端打开市场。配置项 `requireTerminalBlock = true`（默认）时，普通玩家**只能**通过终端进入市场，`/market` 仅管理员可用。

这样做的好处：市场有了实体位置，玩家必须真的跑到终端才能交易；同时把 `/market` 收归管理员，避免单机作弊玩家随手开市场。

### 钱包

界面右上角有钱包区：

| 操作 | 效果 |
|---|---|
| 存入 | 背包里的 `caf:money` → 官网账号余额 |
| 提取 | 官网账号余额 → `caf:money`，经邮箱送达（10 分钟延迟） |

**所有手续费、押金、货款都走官网余额**，不再是背包里的实体币。

### 治理规则（全部在官网服务端执行）

| 规则 | 默认 |
|---|---|
| 上传准入 | 必须绑定账号 |
| **存档创造检测** | 该存档**曾经**切到创造/旁观模式（或建图时允许作弊）→ **永久禁止上传**，购买不受影响 |
| 物品白名单 | 只有白名单内的物品 ID 能上架 |
| NBT 校验 | 只允许标准数据组件，自定义组件拒收 |
| 价格区间 | 有 ≥20 笔成交记录的物品，价格须落在中位数 0.1~10 倍内 |
| 新账号审批 | 前 3 单进人工审批队列 |
| 上架费 | 售价 2%，最低 5 币，不退还 |
| 成交费 | 卖家所得扣 3% |
| 限频 | 每小时最多 10 单，同时最多 30 个挂单 |
| 挂单有效期 | 3 天，过期自动退回邮箱 |
| 邮箱延迟 | 成交后 10 分钟可领取 |

改这些规则**只需要改官网**，玩家不用更新 MOD。

## 3. 安装与配置

1. 把 `gearsandflesh_market-1.0.0.jar` 放进客户端与服务端的 `mods/`；
2. 启动一次，生成配置文件：

`config/gearsandflesh_market-common.toml`

```toml
# 官网市场 API 根地址，结尾不要带斜杠
apiBaseUrl = "https://www.clyfr.cn/market-api"

# 本服务器/单机实例的标识，会上报给官网（用于追溯作弊来源）
serverId = "default"

# HTTP 超时（秒）
requestTimeoutSeconds = 15

# true = 普通玩家只能在市场终端方块处进入市场，/market 收归管理员
requireTerminalBlock = true
```

3. 管理员放置市场终端：`/setblock ~ ~ ~ gearsandflesh_market:market_terminal`

## 4. 工作原理

```
玩家界面 (Client)  ──NeoForge 数据包──►  服务端 MarketService
                                              │
                                              ├─ 本地校验（槽位、数量、序列化）
                                              └─ HTTPS + HMAC 签名 ──► 官网 API
                                                                        │
                                                                  官网数据库
```

**关键顺序（防吞物品）**：挂单时**先**把物品数据交给官网托管，官网确认后**才**从背包扣除；
若期间玩家挪动了物品，立刻调官网取消接口把托管退回。

**身份与安全**：

- 每次请求带 `X-GM-UUID`、`X-GM-Timestamp`、`X-GM-Nonce`、`X-GM-Sign`；
- 签名为 HMAC-SHA256，密钥是该账号绑定后拿到的 token，
  待签串 = `uuid \n nonce \n timestamp \n METHOD \n path \n sha256hex(请求体)`；
- 官网校验时间偏差（±5 分钟）、nonce 防重放、签名一致后才受理；
- 断网时市场界面提示不可用，**不动物品也不动钱**。

**离线降级**：市场属于联网功能。没有网络时游戏本体一切正常，只有市场不可用。

---

## 5. 已知限制

- 必须有可用的官网市场 API，否则绑定/挂单/购买都用不了（本模组不含官网代码）；
- 存档创造检测是**存档级、不可逆**的：一旦在某个存档开过创造，这个存档就永久不能上架（这是刻意设计，购买不受限）；
- 官网侧的行为无法被玩家本地绕过，但**官网自身**需要做好备份与限流。
