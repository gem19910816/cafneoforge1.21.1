# 容器配置

首次进入世界后，NeoForge 会在该世界的 `serverconfig/doomsday_decoration-server.toml` 生成逐方块配置。配置按命名空间分组，每个条目对应 `doomsday_decoration:<方块 id>`；`true` 启用容器，`false` 保留装饰方块的普通交互。

例如：

```toml
[containers.doomsday_decoration]
acrate_2 = true
cabinet = false
woodendrawer = true
```

修改后需要重启服务器或重新进入世界。未列出的新目标默认启用。原版板条箱 `doomsday_decoration:acrate` 已由主模组自带方块实体实现，因此不在附加容器开关中。

格子数与开关音效仍由 `src/main/resources/doomsdaycontainers/container_targets.json` 管理；通常只需编辑服务器配置来选择哪些装饰方块具有容器功能。
