# 移植说明

## 范围

本项目从本地取得的 Survival Instinct 1.0.2 Forge 1.20.1 JAR 开始，目标为
Minecraft 1.21.1 NeoForge。未修改原始 JAR 文件，尽量保留原命名空间、注册 ID 和资源路径。

## 已完成的兼容修复

1. 护甲模型通过 `ArmorModelCache` 缓存并在资源重载时失效，避免 EMF 将同一模型重复创建超过 64 次。
2. 冲刺网络包由服务端检查玩家状态、方向和冷却，客户端不能直接注入任意速度。
3. 便携袋内容改为 1.21 数据组件保存，拒绝递归放袋、复制袋和错误的槽位交换。
4. 容器内容、结构、配方和战利品表按 NeoForge 1.21.1 规范加载。
5. 修正投射物命中、出血计时、护甲套装效果和模型父引用。
6. 硬编码英文提示改为语言键，并提供 `zh_cn.json`。

## 验证

- `gradlew.bat jar --offline`：通过。
- 专用服务器：袋子、容器、结构、配方、套装效果和出血计时回归通过。
- 结构注册：14 个结构全部加载。
- 客户端启动：Survival Instinct 模型加载错误清零。
- JAR 内不包含验证探针源码或验证测试类。

## Paxi 资源包

完整客户端资源已打包为 `Survival-Instinct-Port-zh_CN.zip`，放入
`config/paxi/resourcepacks/`，并加入 `resourcepack_load_order.json`。资源包只使用
`survival_instinct` 命名空间，不覆盖其他模组资源。
