# Sona生存101 — 1.20.1 Forge → 1.21.1 NeoForge 移植说明

## 1. 来源与方法

- 源码：官方仓库 [Scarasol/Sona-Survival-101](https://github.com/Scarasol/Sona-Survival-101) `1.20.1` 分支（MIT）
- 方法：基于官方源码逐包适配，**非反编译**。注册 ID、资源、贴图全部保持不变。
- 目标：NeoForge 21.1.252 / MC 1.21.1 / Java 21

## 2. 构建方式（与仓库其他条目不同，请注意）

NeoForge 官方 maven（maven.neoforged.net）在构建机上不可达，本移植**不使用 ModDevGradle**，
而是直接以本地游戏运行库作为编译 classpath：

- `mc-1.21.1-mojmap-at.jar`：原版 1.21.1 client.jar 经官方映射反混淆 + 应用 NeoForge AccessTransformer（与 NeoForge 生产运行时同为 mojmap 命名，NeoForge 1.21 起生产环境即 mojmap）
- 依赖顺序：neoforge-client.jar → neoforge-universal.jar → mojmap-at.jar → libraries/** → libs/*
- 第三方编译依赖（取自整合包实际运行的 1.21.1 版）：TaCZ 1.1.8、Superb Warfare 0.8.9.2、Traveler's Backpack 10.1.39、GeckoLib 4.9.3、Lost Cities 8.4.6、Iris 1.8.14、MixinExtras 0.4.1
- 打包：`JAVA_HOME=<jdk21> gradle jar`

如需换回标准 MDG（ModDevGradle）工程结构，只需替换 build.gradle，源码无需变动。

## 3. 主要 API 适配

- `net.minecraftforge.*` → `net.neoforged.*`（事件、注册表、fml 包机械迁移）
- 网络：SimpleChannel → `CustomPacketPayload` + `RegisterPayloadHandlersEvent`（8 个包全部重写为 record + StreamCodec）
- `ResourceLocation` 私有构造器 → `fromNamespaceAndPath`/`parse`
- 药水效果 Holder 化（`DeferredHolder<MobEffect,·>` 直接作 Holder 使用）
- `AttributeModifier` 改用 ResourceLocation id（替代 UUID）
- 物品 NBT → `DataComponents.CUSTOM_DATA`；`isEdible()` → `has(DataComponents.FOOD)`
- 实体 Forge `getPersistentData()` → NeoForge 仍存在于 `IEntityExtension`，按接口调用
- GeckoLib 3 → 4（包层去掉 `.core`）
- 箱子锁从 Forge `BlockEntity#getPersistentData` 迁移为 mixin 字段 + `saveAdditional/loadAdditional` 持久化
- 混配置文件按 NeoForge 要求在 `neoforge.mods.toml` 中 `[[mixins]]` 显式声明（Forge 自动扫描已取消）
- MixinExtras 0.4.1 以 jarJar 内嵌（NeoForge 不自带）
- 数据包：`data/forge/tags` → `data/c/tags`，目录单数化（`tags/item` 等）
- 着色器：`fog.glsl` 覆盖与自带 `rendertype_entity_dither` 适配 1.21.1 的 `fog_distance(vec3,int)` 签名
- `ZombieEvent.SummonAidEvent` NeoForge 已删除 → 以 `LivingDamageEvent` + 瞬时属性修饰复刻语义

## 4. 顺带修复的原版缺陷（经代码审查发现）

- **可无界循环挂死线程**：闪电束渲染/抛物线落点计算加上限 200 次迭代
- **LockPacket 服务端零校验**：任意客户端可远程锁他人箱子 → 加距离/加载校验；修正 `flag`/`LockFlag` 键名不匹配
- **SoundDecoyPacket** 信任客户端坐标刷实体 → 加 64 格距离校验与 amplifier 钳制
- **聊天元数据注入**：`blurMessage` 裸 `parseInt` 可被伪造消息崩客户端 → 加格式校验；另修系统消息 `getBoundChatType()` 为 null 导致 NPE 断线（1.21 包处理异常即断连）
- `EffectEventHandler.summonAid` 非 static 不生效 → static（并对 NeoForge 缺失事件做语义复刻）
- `soundDecoyTarget` 对从磁盘加载的实体重复叠加 AI goal → 加 `loadedFromDisk`/客户端守卫
- `DeathManager` 死亡背包缓存循环内误删 + 永不清理 → 修正并加登出清理
- `CompoundTagMixin` 全局改 equals 不改 hashCode 且双份深拷贝 → 同步 hashCode、浅拷贝剔除
- `LocalPlayerMixin` 每 tick 发输入包 → 输入变化才发
- `LivingEntityMixin` 每 tick 无条件写 SynchedEntityData（全实体网络同步刷屏）→ 值变化才写
- 箱子锁客户端/服务端独立随机不一致 → 仅服务端判定
- `KeyboardHandlerMixin` 的 F3 键笔误（modifiers==F3）
- 每帧 `new ResourceLocation`/`RenderType.create` 等渲染热路径分配 → 常量/缓存
- 配置白名单热路径字符串线性扫描 → 预编译 HashSet
- 详见仓库根 `PORTING_GUIDE.md` 与各文件注释

## 5. 验证状态

- `javac 21` 编译 **0 error**（151 个源文件）
- 全部 70+ mixin 注入点逐一与 1.21.1（含 NeoForge 补丁版）字节码核对
- 实机（整合包 212 模组环境）：启动到主菜单、创建世界、区块保存、感染/腐坏/锁箱基本路径人工实测通过
- **已知限制**：安装 Sodium 0.8 时首页提示"资源包可能与 Sodium 不兼容"（因覆盖原版 `fog.glsl`）；Sodium 接管雾效管线后感染区自定义雾效可能减弱。原模组的 Embeddium 适配分支不适用于官方 Sodium 0.8，未做深度适配。
