# 1.21.1 NeoForge 迁移测试版

构建日期：2026-10-10。原作者及署名保持不变，本包是迁移测试版，不是作者官方发布。

## 安装

环境：Minecraft 1.21.1、NeoForge 21.1.252 或更新的 21.1.x、Java 21。运行测试使用 21.1.255；21.1.252 仅已放开依赖范围，尚未实机验证。
将两个 JAR 同时放入客户端和服务端的 mods 目录；单人游戏只需客户端。
移除原来的 Forge 1.20.1 版本，不要重复安装。
正式存档请先备份，再在测试存档验证。

万象棱镜继续使用原有 config/item_rarity/grade_register 和 grade 配置。
翻箱倒柜使用 config/rummage-common.toml。稀有度定义/贴图仍需客户端与服务端一致。
本包不自动下载第三方稀有度配置，也不附带第三方模组。

## 源码构建

本仓库的源码位于相邻的 万象棱镜/ 和 翻箱倒柜/，两个目录必须保持相邻。
第三方依赖 JAR、JDK、Gradle 缓存和测试世界不随源码包分发。
设置 JAVA_HOME 为 Java 21，然后在仓库根目录运行：

```powershell
.\万象棱镜\prepare-dependencies.ps1
.\翻箱倒柜\prepare-dependencies.ps1
cd 翻箱倒柜
.\gradlew.bat clean build
```

Gradle 8.8 wrapper 会构建两个模组，使用 ModDevGradle 2.0.148 / NeoForge 21.1.255 开发环境；发布包依赖范围为 NeoForge 21.1.252 及更新的 21.1.x。
首次构建需要联网下载 Gradle、插件及 Minecraft 开发依赖。

开发服务器检查：`.\gradlew.bat -PportTests :runServer`，读取 run/port-test-results.txt 判断结果，不能仅看 Gradle 退出码。
客户端检查：先准备 run/saves/PortTest 测试世界，再运行 `.\gradlew.bat -PportTests :runClient`，读取 run/port-client-test-results.txt。
可选联动检查还需提供 Sophisticated Core / Backpacks 对应依赖，再加 `-PcompatTests`。
原仓库 README.txt 为 Forge 模板说明；本文件中的构建方法适用于本迁移版。
